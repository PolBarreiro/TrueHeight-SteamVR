# TrueHeight Steam store copy

## Short description

Stay at your chosen standing height in SteamVR while sitting, reclining, or
changing posture. TrueHeight is a lightweight Windows tray utility that adjusts
the temporary SteamVR play-space offset and restores it when you stop.

## About this software

TrueHeight helps seated and mobility-limited VR players keep a consistent
in-game standing height without repeatedly running Room Setup.

Set your normal standing eye height, start the lock, and TrueHeight gently
adjusts SteamVR's temporary standing-space offset as your physical posture
changes. It works outside the game process: no injected DLLs and no game files
are modified.

### Features

- Automatic target-height stabilization through SteamVR
- Settings window plus unobtrusive notification-area operation
- Adjustable smoothing, deadzone, and comfort speed limit
- Global pause, reload, and emergency restore hotkeys
- Automatic clean-exit restore
- Per-user settings that Steam updates do not overwrite
- Designed to work independently of the running VR title

### Important behavior

Height stabilization intentionally cancels physical crouching and other vertical
head movement. You may still crouch physically, but you must also press the
game's crouch input or the player will not crouch while the lock is on.
Do not run another SteamVR play-space offset or motion tool at the same time.
Headset and runtime compatibility can vary.

## Minimum system requirements

- OS: Windows 10 or Windows 11, 64-bit
- Processor: x64-compatible processor
- Memory: 100 MB RAM
- Storage: 10 MB available space
- VR: SteamVR and a SteamVR-compatible headset
